EARNX SIMPLE ADMIN LOGIN

1. Open src/main.jsx.
2. Find:
   const ADMIN_TELEGRAM_ID="YOUR_TELEGRAM_ID";
   const ADMIN_PIN="CHANGE_ME_1234";
3. Replace YOUR_TELEGRAM_ID with your numeric Telegram ID.
4. Change CHANGE_ME_1234 to your own PIN.
5. Save, build and deploy.
6. Open EARNX -> Menu -> Admin Panel.
7. Enter the same Telegram ID and PIN.

Note: This is a simple frontend gate, not server-side security. Do not use a sensitive password here.
