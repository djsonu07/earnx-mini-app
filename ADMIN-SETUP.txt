EARNX SECURE ADMIN SETUP

The old frontend Telegram-ID + PIN gate is removed.
Admin access now requires Firebase Authentication (Email/Password) AND Custom Claim admin=true.

1. Firebase Console -> Authentication -> Sign-in method -> enable Email/Password.
2. Create your admin user with a strong password.
3. Firebase Console -> Project settings -> Service accounts -> Generate new private key.
4. Save the JSON OUTSIDE this project and never upload/commit it.
5. On your PC, set GOOGLE_APPLICATION_CREDENTIALS to that JSON path.
6. In this project run:
   npm install
   npm run set-admin -- YOUR_ADMIN_EMAIL
7. Sign out/in and open EARNX Admin.

SECURITY
- No admin PIN or service-account key is shipped in frontend code.
- Firestore admin writes require request.auth.token.admin == true.
- Keep the service-account JSON private.
- For complete production hardening, move reward/withdrawal balance mutations to trusted Cloud Functions/backend and verify Telegram WebApp initData server-side.
